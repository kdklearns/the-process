# Reverse String

The input `s` is an array of characters representing a string. Write a function that reverses its character order directly in the array.

Modify `s` **in place**, using only `O(1)` additional memory.

## Example 1

```text
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

## Example 2

```text
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

## Constraints

- `1 <= s.length <= 10⁵`
- Every `s[i]` belongs to the printable ASCII character set.
