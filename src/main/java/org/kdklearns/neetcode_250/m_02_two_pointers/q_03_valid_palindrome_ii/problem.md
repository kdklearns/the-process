# Valid Palindrome II

Determine whether the string `s` can form a palindrome by removing zero or one character.

Return `true` if this is possible; otherwise, return `false`.

## Example 1

```text
Input: s = "aba"
Output: true
```

## Example 2

```text
Input: s = "abca"
Output: true
```

Explanation: Removing `'c'` leaves `"aba"`, a palindrome.

## Example 3

```text
Input: s = "abc"
Output: false
```

## Constraints

- `1 <= s.length <= 10⁵`
- Every character in `s` is a lowercase English letter.
