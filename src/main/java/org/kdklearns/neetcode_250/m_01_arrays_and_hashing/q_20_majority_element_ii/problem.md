# Majority Element II

For an integer array `nums` containing `n` elements, return every value whose frequency is greater than `⌊n / 3⌋`.

## Example 1

```text
Input: nums = [3,2,3]
Output: [3]
```

## Example 2

```text
Input: nums = [1]
Output: [1]
```

## Example 3

```text
Input: nums = [1,2]
Output: [1,2]
```

## Constraints

- `1 <= nums.length <= 5 * 10⁴`
- `-10⁹ <= nums[i] <= 10⁹`

## Follow-up

Can you achieve `O(n)` running time with `O(1)` auxiliary space?
