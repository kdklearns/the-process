# Longest Common Prefix

Given an array of strings `strs`, return the **longest common prefix** shared by all the strings.

If the strings have no common prefix, return an empty string `""`.

## Example 1

```text
Input: strs = ["bat","bag","bank","band"]
Output: "ba"
```

## Example 2

```text
Input: strs = ["dance","dag","danger","damage"]
Output: "da"
```

## Example 3

```text
Input: strs = ["neet","feet"]
Output: ""
```

## Constraints

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- Each non-empty `strs[i]` consists of lowercase English letters.
