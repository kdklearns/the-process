# Valid Anagram

Given two strings `s` and `t`, return `true` if they are anagrams of each other. Otherwise, return `false`.

Two strings are **anagrams** if they contain the same characters, with each character appearing the same number of times, regardless of order.

## Example 1

```text
Input: s = "racecar", t = "carrace"
Output: true
```

## Example 2

```text
Input: s = "jar", t = "jam"
Output: false
```

## Example 3

```text
Input: s = "x", t = "x"
Output: true
```

## Constraints

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` and `t` consist of lowercase English letters.
