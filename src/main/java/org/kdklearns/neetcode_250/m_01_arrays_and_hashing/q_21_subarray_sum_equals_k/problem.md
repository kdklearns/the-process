# Subarray Sum Equals K

For an integer array `nums` and an integer `k`, count how many non-empty, contiguous segments have a sum of `k`.

Return this count. Each such segment is called a **subarray**.

## Example 1

```text
Input: nums = [1,1,1], k = 2
Output: 2
```

## Example 2

```text
Input: nums = [1,2,3], k = 3
Output: 2
```

## Constraints

- `1 <= nums.length <= 2 * 10⁴`
- `-1000 <= nums[i] <= 1000`
- `-10⁷ <= k <= 10⁷`
